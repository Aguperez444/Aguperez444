## Sobre mí

Soy estudiante avanzado de **Ingeniería en Sistemas de Información en la UTN FRC**, en Córdoba, Argentina. Mi foco está en el desarrollo backend con **Python y Java**, las APIs REST y la arquitectura de software.

- Participo en el desarrollo de **Ganker**, una plataforma para conectar jugadores y formar equipos.
- Desarrollé una aplicación de **inventario y ventas utilizada diariamente en un comercio desde 2023**.
- Trabajo con arquitectura hexagonal, pruebas automatizadas y despliegues con Docker y CI/CD.
- Me interesan las integraciones, la automatización y la infraestructura cloud.

## Proyectos destacados

### [Ganker](https://github.com/Aguperez444/Ganker)

Plataforma colaborativa para encontrar compañeros de juego y formar equipos. Participo en el desarrollo backend, con APIs REST, comunicación en tiempo real mediante WebSockets e integraciones con servicios externos.

Trabajo con arquitectura por capas y puertos y adaptadores, migraciones, pruebas automatizadas y un pipeline de CI/CD para desplegar en Oracle Cloud Infrastructure.

**Stack:** Python · FastAPI · SQLAlchemy · PostgreSQL · React · Docker · GitHub Actions

[Ver repositorio](https://github.com/Aguperez444/Ganker) · [Abrir aplicación](https://gankerweb.app/)

### [Sistema de inventario y ventas](https://github.com/Aguperez444/app_punto_de_venta)

Aplicación de escritorio que desarrollé para un comercio minorista, **en uso diario desde 2023**, con más de **1.000 productos** en el último recuento. Permite gestionar stock y precios, registrar ventas y consultar reportes.

La versión utilizada en el comercio emplea Tkinter y SQLite. Posteriormente realicé una refactorización con arquitectura hexagonal, SQLAlchemy, PostgreSQL y pruebas automatizadas.

**Stack:** Python · Tkinter · SQLite · SQLAlchemy · PostgreSQL · Pytest

[Ver repositorio](https://github.com/Aguperez444/app_punto_de_venta)

### [Backend de microservicios](https://github.com/Aguperez444/backend_contenedores)

Proyecto académico en equipo con servicios independientes, API Gateway y autenticación y autorización por roles mediante Keycloak y OAuth2/JWT.

**Stack:** Java · Spring · Spring Cloud Gateway · Keycloak · Docker Compose

[Ver repositorio](https://github.com/Aguperez444/backend_contenedores)
